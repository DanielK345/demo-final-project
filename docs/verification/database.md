## `alembic check` — model/migration drift

`alembic check` báo drift do index names và check constraints từ migration cũ khác với ORM declaration hiện tại. Đây là cosmetic differences (indexes tồn tại dưới tên khác trong DB), KHÔNG ảnh hưởng data integrity. Các phần drift:

- Index rename: `ix_bookings_session_created` → implicit; `ux_bookings_quote_id` → UniqueConstraint
- Nullable: `places.created_at`, `route_snapshots.created_at` → ORM có `server_default=func.now()` nên nullable bất đồng là cosmetic
- JSON type variants: `JSON(astext_type=Text())` vs `JSON()` — driver-level, không ảnh hưởng runtime

Không cần migration sửa vì PostgreSQL schema trên live đã đúng — drift chỉ giữa ORM metadata và autogenerated comparison.

## Trạng thái trung thực

Code persistence, migration, Maps subsystem và test đã hoàn tất. PostgreSQL live chưa được mutate lên head mới (`fc877ccd583a`). Lệnh `alembic upgrade head` bị chặn vì cần phê duyệt rõ ràng cho schema/RLS mutation trên database live. Vì vậy:

- không ghi `LIVE_VALIDATED` cho migration mới;
- không chạy script acceptance trước khi DB ở đúng revision;
- giữ production readiness fail-closed;
- thao tác owner cần làm nằm trong `mustdo.md` và `docs/database_supabase.md §6`.

Sau khi được phê duyệt, chạy:

```powershell

```

Chỉ cập nhật tài liệu này sang `LIVE_VALIDATED` khi lưu được output pass, timestamp, environment và người phê duyệt.
